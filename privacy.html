Privacy Policy — Second Brain

Last updated: 30 September 2026

Who uses this application

Second Brain is a private tool used only by its owner, Michael Bonera, with his own Google accounts. It is not offered to the public and has no other users.

What data it accesses

With the owner's explicit consent, the application accesses Gmail messages, Google Calendar events and Google Drive files of the owner's own accounts, using the scopes granted on the Google consent screen.

How the data is used

Data is read by command-line tools running on the owner's own computer, to triage email, synchronise calendar events with personal notes and read personal files. Summaries may be stored in the owner's private notes on the same computer. The owner may use an AI assistant on his computer to process this data on his behalf.

Sharing

Data is not sold, not used for advertising and not shared with third parties, except for the processing performed by the AI assistant used by the owner as described above.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.
